# Security Policy

## Supported versions

Only the [latest release](https://github.com/emrebal98/yaltri/releases/latest) gets security fixes.
Yaltri checks for updates from **Settings → About**; on Windows, run the new download to update,
and on Linux run `install.sh` again.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately through GitHub instead:
**[Report a vulnerability](https://github.com/emrebal98/yaltri/security/advisories/new)**
(Security tab → Report a vulnerability). Only the maintainer sees the report.

It helps to include:

- the Yaltri version and your system (Windows version, or Linux distribution and desktop),
- what an attacker can do, and the steps or a proof of concept to reproduce it.

Yaltri is maintained in spare time. You can expect a first reply within a week. Once a fix is
released, the advisory is published with credit to you, unless you prefer otherwise.

## Scope

In scope: the Yaltri application, `install.sh`, and the release builds published on GitHub.
Problems in a dependency are best reported to that project; tell us too if Yaltri is affected.
